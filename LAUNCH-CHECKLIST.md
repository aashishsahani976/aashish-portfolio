# Launch checklist

- [ ] Replace all five development placeholders with real projects and approved images.
- [ ] Verify email and phone should be public.
- [ ] Verify Instagram destination.
- [ ] Add the final résumé PDF, then enable the download in `src/lib/profile.ts`.
- [ ] Set `NEXT_PUBLIC_SITE_URL` to the actual deployment URL.
- [ ] Update `public/robots.txt` with the same URL.
- [ ] Run `npm run typecheck`, `npm run lint`, and `npm run build`.
- [ ] Check mobile and desktop layouts and keyboard navigation.
- [ ] Test the mailto fallback on a device with an email app configured.
- [ ] Review Vercel build logs and run Lighthouse after deployment.
